# 🌿自然探險小隊 (Nature Adventure Squad)
這是一款專為 國小三、四年級學生 設計的線上互動式教學遊戲。透過「觀察紀錄分析」的情境，引導學生利用自然科學課所學的地質、生物、能源與環境知識進行解謎挑戰。

## 🚀 立即開始遊戲
點擊下方連結即可開始挑戰：
👉 **[點擊這裡開始遊戲](https://weddy1225-blip.github.io/Science01-v1-/)**

---

## 🎮 遊戲特點
*   **探險筆記情境**：將題目設計為第一人稱的「觀察紀錄」，模擬科學家在田野調查時看到的現象。
*   **80提完整題庫**：涵蓋地質（岩石/化石）、水生與陸生植物、水生動物、能源電力及環境災害防治。
*   **全自動進度判斷**：
**   利用 localStorage 技術，系統會自動記錄已挑戰過的題目。
**   無重製按鈕設計：系統會自動判斷進度，在完成全題庫 80 題前不會重複出題。
**   全數完成後，系統會自動提示並詢問是否重新開始全紀錄挑戰。
*   **視覺排版優化**：採用綠色系視覺主題，營造自然科學的學習氛圍。

---

## 📚 教學目標 (符合四年級認知)
根據國小自然科學領域課程綱要設計，重點包含：
*   **地質科學**：辨識根（軸根/鬚根）、莖（木本/草本）、葉（網狀脈/平行脈）的特徵與繁殖方式。
*   **生物多樣性**：
**   **植物**：認識水生植物的構造（布袋蓮、水蘊草）及陸生植物的根莖葉脈。
**   **動物**：了解水生動物呼吸器官與昆蟲的基礎特徵。 
*   **能源與環境**：認識再生能源（風力、太陽能）與地震、颱風等自然災害的防護知識。

---

## 🛠️ 技術實作
*   **開發語言**：HTML5, CSS3, JavaScript (Vanilla JS)。
*   **狀態紀錄**：使用 Window.localStorage 儲存 playedIds 陣列，即便關閉網頁也會記得進度。
*   **自動化流程**：
**  **初始化**：自動比對總題庫與已玩過的ID，計算剩餘題數。
**  **出題**：從剩餘題庫中隨機抽選5題組成一局任務。

---

## 🚀 部署說明
1.  下載本專案的 `index.html` 檔案。
2.  將檔案上傳至 **GitHub Pages** 或任何網頁伺服器。
3.  開啟連結即可開始遊戲。
    *   **遊戲規則**：每局 5 題觀察紀錄。
    *   **結算系統**：結算時根據正確率授予「傳奇觀察家」、「精英特派員」或「實習探險隊員」。
